# 第三方许可材料

`loong_gui_ctrl/` 保存两个 GUI 使用的 Python、PyQt5 / Qt、PyInstaller，以及控制台的
Paramiko、密码学依赖许可材料；具体构建版本见根目录 `RELEASE.json`。
PyQt5 wheel 的包元数据标注 GPL v3，对应文本保存在 `PyQt5/LICENSE.GPL3`。
其他材料从所用发行包原样复制。

仿真原生模块的 LICENSE、NOTICE 在 `loong_gui_sim/licenses/`，SDK 许可在其
`runtime/license`。训练框架的 LICENSE 和源码版权声明保留在训练目录中。
