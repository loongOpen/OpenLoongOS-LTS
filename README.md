# OpenLoongOS LTS

**OpenLoongOS LTS 是面向人形机器人的运动控制算法与全链仿真框架，旨在打通策略训练、仿真验证与机器人控制的开发流程。**

项目计划逐步开放行走、跳舞、越障、身外化身四套算法，并通过统一的全链仿真 UI，连接模型训练、Sim2Sim 验证与真机部署。

当前阶段主要交付三部分内容：**行走算法训练代码、全链仿真运行组件及可视化操作界面**。其中，训练代码开放源码，全链仿真运行组件与 GUI 以预编译形式提供。

## 05 架构与接口

### 训练与仿真
当前版本采用独立的算法训练环境与仿真运行环境：

**训练侧**：基于 MuJoCo-Warp 的训练框架，提供行走策略训练、检查点回放等能力。

**仿真侧**：基于预编译运行组件，提供机器人模型、控制链及可视化仿真界面。

**策略接口**：通过明确的观测协议、动作输出及关节映射，将训练得到的策略接入仿真运行环境。

训练引擎与仿真运行包中的 MuJoCo 属于不同的运行环境，相关依赖及版本应分别管理，不应混用。

### 模型与策略接口

仿真采用 26 轴模型，策略使用 20 个动作输出，其余 6 个腕关节保持默认姿态；两套模型的关节映射已经显式配置，并非可以任意互换。

示例策略接口为 float32 `obs[1,700] → actions[1,20]`，10 帧观测历史。关节顺序、默认角度、动作缩放及训练 PD 元数据等具体定义，以模型说明及实际配置为准。仿真驱动采用固定 PD 控制，训练侧元数据并不能直接证明两侧动力学参数完全一致。
